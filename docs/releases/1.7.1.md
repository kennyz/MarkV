# MarkV 1.7.1

## What's new

- Adjust document and file-sidebar font sizes separately in Settings. Changes take effect immediately and are remembered between sessions.
- Use the View menu to increase (`Command-=`), decrease (`Command--`), or reset (`Command-0`) the document font size without losing your draft or caret position.
- Enjoy a lighter Warm Paper theme across the native interface and document editor.
- Start with a larger 1280 × 820 default window.
- Read larger file names and previews in the sidebar, with full file names available on hover.
- Compare equivalent version numbers correctly when checking for updates.

## Download and install

Requires macOS 14 or later and an Apple Silicon Mac (`arm64`). Open the DMG and drag **Markv.app** to **Applications**.

This build is ad-hoc signed and is not notarized by Apple. macOS may block the first launch. After attempting to open the app, use **System Settings → Privacy & Security → Open Anyway** if the warning appears, then confirm that you want to open it.

The release includes `SHA256SUMS.txt` for checking the downloaded DMG.
